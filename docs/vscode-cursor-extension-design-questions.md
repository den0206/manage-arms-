# ManageArms VS Code / Cursor 拡張版 — 設計判断質問票

## 目的

ManageArms の機能を VS Code / Cursor 拡張へ移行するにあたり、実装前に決める事項を整理する。
各質問の「推奨」は現行 Mac App の安全性、既存の Swift テスト資産、段階移行のしやすさを基準にした初期案であり、最終決定ではない。

## 現時点で分かっている制約

- MCP・Skill・Subagent・Plugin の管理機能は、デスクトップ拡張へ概ね移行できる。
- macOS メニューバー常駐と、IDE 終了後のブラウザ検知は拡張だけでは実現できない。
- ローカルのホームディレクトリと CLI を扱うため、Web 版ではなくデスクトップ版専用になる。
- VS Code / Cursor の複数ウィンドウや同時起動による競合対策が必要になる。
- 現行の `ManageArmsCore`、`WriteGuard`、ダウンロード制限、ロールバック、375件のテストは重要な移行資産である。
